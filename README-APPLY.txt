IDEARE UI POLISH PATCH
======================

Source reviewed first:
https://github.com/ferhan02/IDEARE-CREATION
(default branch: main)

What this patch changes
-----------------------
1. Replaces the main IdeaRE text wordmarks with the supplied IDEARE logo.
2. Uses IDEARE capitalization in the modified shared headers/login/designer areas.
3. Adds a shared UI polish stylesheet for buttons and interactive controls.
4. Adds polished hover/focus/active/disabled states for primary, normal,
   approval, danger, login, preset, menu and utility buttons.
5. Converts the top-right staff identity area into a hover/focus/click dropdown:
   - Manage profile
   - Sign out
6. Shows job title as the position when available, otherwise falls back to role.
7. Keeps the profile dropdown usable on touch devices and by keyboard.
8. Includes the supplied logo as assets/images/ideare-logo.png.

How to apply
------------
Extract this ZIP directly into:
C:\xampp\htdocs\IDEARE CREATION\

Allow Windows to merge folders and replace files when prompted.

No database changes are required for this patch.
