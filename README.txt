IdeaRE - Sidebar Navigation Search Patch
=======================================

Install:
1. Extract this ZIP over your existing IdeaRE Creation project root.
2. Allow these two files to be replaced:
   - includes/staff/sidebar.php
   - assets/css/crm-projects.css
3. Hard-refresh the browser (Ctrl+F5).

What it adds:
- Real-time filtering of sidebar navigation links.
- Automatically hides empty section headings while filtering.
- Result count while typing.
- Clear (x) control.
- Press Escape to clear the filter.
- Press Enter to open the first matching page.
- Press / anywhere outside a form field to focus the sidebar search.

No database changes are required.
