Adding another supported photo (PNG/JPG/JPEG/WEBP/AVIF) to a style folder will
add a concept automatically. Photo filenames containing `kitchen`, `media`,
`living`, `tv wall`, `wardrobe`, or `bedroom` are assigned to the corresponding
room filter. Others appear under the `Other` category.

Optional `cover.png`, `cover.jpg`, `cover.webp`, etc. sets the style card image.
Otherwise the first uploaded kitchen image is used.
