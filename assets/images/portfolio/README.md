# IDEARE homepage portfolio photographs

Each project has its own folder. Add the project photographs directly into the matching folder below. Supported formats: JPG, JPEG, PNG, WEBP and AVIF.

## Choosing the cover photograph

The homepage displays **one standardized 16:9 cover per project**. The cover is selected in this order:

1. A file named `cover.jpg`, `cover.png`, `cover.webp` or `cover.avif` (this is the manual override and always wins).
2. A recognizable image name such as `Storefront.png`, `Front View.jpg`, `Duty Free.png`, `Kilang Yakult.png`, `Panggung Bangsawan.png` or the venue name.
3. If no preferred name is found, the first image alphabetically is used.

All other supported images in the same folder are automatically included in that project's popup gallery. You do not need to edit PHP or JavaScript when adding photographs.
